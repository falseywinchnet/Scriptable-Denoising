# Scriptable Denoising experiment — Cleanup v2 demonstrator

2026-09-16

This prerelease introduces an experimental scriptable denoising wrapper, with
modified Cleanup v2 as its first supplied demonstrator. Native transforms, fixed
workspaces, compiled script chaining, diagnostics and the viewer are reusable
facilities for other experiments. The optional enhanced magnitude representation
may interest ML vision research, but its usefulness there remains unknown.

It preserves the version tested live in SDR# Next (.NET 10, x64)
under Wine 11.17 with WASAPI. The user confirmed that the 3 kHz gap is gone,
squelch works, and, after restoring the original After source relationship,
**speech is restored**. This is an open denoising experiment, with no sliders.

## Included

- Precompiled `SDRSharp.Cleanup.dll`: Reload, success/error label, Bypass, Squelch.
- `Cleanup.dll` bootstrap, native `CleanupNative.dll`, C headers and host example.
- One editable `Filter.py`, strict explicitly typed Numba compilation on Reload.
- Private Windows x64 CPython 3.12.10, NumPy 2.3.5, Numba 0.63.1, llvmlite 0.46.0.
- Native cross-platform viewer source; packaged Windows viewer with Pause.
- Native DSP/bfft source, tests, research references and algorithm documentation.

C# wrapper source, host SDK assemblies, Git packs, caches and build trees are
excluded from the public source snapshot and runtime archive. The C# wrapper is
provided as a compiled artifact. The original Cleanup and SDRSharp-Cleanup-Plugin repositories remain separate
and unchanged. This experiment is published in Scriptable-Denoising.

## Defaults and repairs

Registration off; central enhanced-magnitude guide with full Nyquist coverage;
receiver-aware population; complete legacy two-pass Cleanup mask; harmonics retired.
The optional rolloff-population and registration experiments remain explicit
Filter.py choices. Reload reconstructs FFT/STFT plans and persistent state.

The mono early tap no longer reinterprets adjacent samples as stereo/IQ or writes
back into the radio stream. This removed the reproduced 3 kHz notch. The mask now
uses post-AGC content amplitudes, while early input retains whole-block squelch
control. See [source routing](mask-source.md) and [mono tap](mono-analysis-tap.md).

## Verification

- Actual SDR# load and live reception; user-confirmed gap, squelch and speech fixes.
- 89 active live blocks: median **26.317 ms**, peak **45.864 ms**, versus a
  **170.667 ms** block interval. No faults or deadline misses in that 15-second run.
  48 kHz, stereo host with identical channels, 6 kHz receive bandwidth, Wine host.
- Self-contained Windows package host: load, 16 audio blocks, control toggles,
  Reload and shutdown pass. Every packaged file hash verified. The 16-block smoke
  ran alongside SDR# and measured 51.32 ms median / 90.99 ms peak.
- Original C++ mask comparison in six After-mode bandwidth/squelch cases:
  maximum central-mask error **1.67e-16**.
- Native source-routing regression: 1000x difference in early input level with
  equal content produces equal output. Silent early input still closes squelch.
- RFFT/ODFT identity, constant-gain, reload and viewer publication checks pass.
- All 40 script methods explicitly compiled; 27 tested native callback invocations
  show zero Numba-runtime allocations. This does not measure every host allocation.

The declared engine latency remains 16,768 samples / 349.33 ms at 48 kHz before
host buffering. Timing on this Wine setup does not establish performance on every
Windows system. SDR Console has not been tested against this new C ABI.
Mac/Linux use the same native/viewer sources but require their own runtime bundles.

## Install

Download the Windows x64 prerelease archive and extract its `Cleanup` folder into
SDR#'s `Plugins` directory with the host closed. Keep all adjacent files and the
`_python` directory together. Use a matching .NET 10 x64 SDR# Next installation.
No separate Python installation is required. First compilation takes longer than
audio processing. Use WASAPI under Wine. See [bundle instructions](windows-bundle.md).
