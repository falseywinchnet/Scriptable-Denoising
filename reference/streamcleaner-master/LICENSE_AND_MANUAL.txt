Now, the readme:

If you can't understand the source code, don't use it.
I do recommend the python especially because it is the most validated.

The VST features some extra spice and secret tweaks that make it super effective.

The C++ uses entirely stack memory, except the python. You need to set 4mb for float 16mb for double of reserved stack to run this, if you compile it yourself. 
it's all fixed size memory, pre-allocated arrays, etc, so you'll never have to worry about memory overrruns or stuff like that.

WHAT YOU REALLY WANTED TO KNOW:
the VST interface contains only four settings.
the first, nominally called the "entropy similarity" slider, concerns the noise-similarity threshholding. lower permits more signal but can result in some noise. 
the method is, however, fairly robust at all settings as offered to you.
the second, nominally called the "bins" slider, concerns a low pass filter applied to the processing and the output.
The range provided is suitable for single sideband configuration.
the bins slider also sets the number of frequency bins used in the entropy and threshholding estimation. 
it is recommended to set this at or slightly above your input bandwidth if you wish to lower the thresholding floor a little bit,
and to set it at or slightly below your input bandwidth for the most accurate behavior. 
it is recommended to use this program primarily with an input bandwidth of around 3.6khz and a low pass internally at 3656.
the third slider is a multiplier that adjusts a cutoff inside of the filter. the behavior was recently discovered, but to replicate
the classical function, use the full range (1.0). I recommend setting it anywhere between 0.10 and 0.40, wherever you are comfortable.
the enable button disables or enables all processing, for comparison testing.

it is recommended you use a notch filter and no other noise reduction methods before this program.
this program is immune to noise in the frequency domain(impulse noise, guassian noise, similar)
but does not have any ability to filter out IMD. it will recognize IMD as signal.
The presence of a carrier is often enough to break it, so use a notch filter.
Other denoising methods *before* this filter will damage it's ability to effectively isolate noise from signal, so they are not recommended.
if desired, they can be added after this filter.

The delay on this software is 170.66ms.
